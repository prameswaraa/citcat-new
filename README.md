# Citcat - Syarat dan Ketentuan Penggunaan Source Code

**Terakhir diperbarui:** 8 Januari 2026

---

## 1. Definisi

- **"Source Code"** merujuk pada seluruh kode sumber Citcat yang disediakan dalam paket ini.
- **"Pembeli"** merujuk pada individu atau entitas yang telah menyelesaikan kelas "Lolos Tech Provider" dan menerima Source Code sebagai bonus.
- **"Penyedia"** merujuk pada pemilik dan pengembang asli Citcat.

---

## 2. Status Source Code

Source Code Citcat ini diberikan sebagai **BONUS** dari kelas "Lolos Tech Provider". Dengan menerima Source Code ini, Pembeli memahami dan menyetujui bahwa:

### 2.1 Bukan Produk Utama
- Source Code ini adalah **bonus tambahan**, bukan produk utama yang dibeli.
- Nilai utama adalah dari materi kelas "Lolos Tech Provider" itu sendiri.

### 2.2 Tidak Ada Jaminan
- Source Code disediakan **"AS IS"** (sebagaimana adanya).
- Tidak ada jaminan bahwa Source Code akan berfungsi sesuai kebutuhan spesifik Pembeli.
- Tidak ada jaminan ketersediaan, kelengkapan, atau kesesuaian untuk tujuan tertentu.

---

## 3. Dukungan dan Pembaruan

### 3.1 Pembaruan Bug Fix (Maksimal 1 Tahun)

- Penyedia **dapat** (namun tidak wajib) menyediakan pembaruan untuk perbaikan bug.
- Periode pembaruan bug fix adalah **maksimal 1 (satu) tahun** sejak tanggal pembelian kelas.
- Setelah periode tersebut, tidak ada kewajiban untuk menyediakan pembaruan apapun.

### 3.2 Pembaruan Fitur

- Pembaruan fitur baru **TIDAK DIJAMIN**.
- Penyedia dapat merilis fitur baru, namun ini sepenuhnya berdasarkan kebijaksanaan Penyedia.
- Pembeli tidak berhak menuntut fitur baru atau peningkatan.

### 3.3 Dukungan Teknis

- Dukungan teknis **TIDAK TERMASUK** dalam bonus ini.
- Pembeli bertanggung jawab penuh atas instalasi, konfigurasi, dan pemeliharaan.
- Komunitas atau forum dapat digunakan untuk diskusi sesama pengguna (jika tersedia).

---

## 4. Hak Penggunaan

### 4.1 Yang Diizinkan

✅ Menggunakan Source Code untuk keperluan pribadi atau bisnis sendiri  
✅ Memodifikasi Source Code sesuai kebutuhan  
✅ Melakukan white-label (mengganti branding)  
✅ Membuat turunan (derivative works) untuk penggunaan internal  
✅ Menjalankan sebagai layanan SaaS untuk klien Anda (klien mengakses via browser, bukan install)  

### 4.2 Yang TIDAK Diizinkan

❌ **Menjual kembali** Source Code dalam bentuk apapun  
❌ **Memberikan sebagai bonus** kepada pihak lain  
❌ **Mendistribusikan** Source Code secara gratis maupun berbayar  
❌ **Membagikan** Source Code kepada pihak ketiga  
❌ **Mempublikasikan** Source Code ke repository publik (GitHub, GitLab, dll)  
❌ **Menginstall untuk klien** (memberikan Source Code atau instalasi terpisah kepada klien)  
❌ **Mengklaim** sebagai pembuat/pengembang asli Source Code  
❌ **Menghapus** atribusi atau credit kepada pembuat asli  

### 4.3 Klarifikasi SaaS vs Install

| Model | Status |
|-------|--------|
| Anda hosting, klien akses via browser | ✅ **BOLEH** |
| Anda install di server klien | ❌ **TIDAK BOLEH** |
| Anda berikan Source Code ke klien | ❌ **TIDAK BOLEH** |
| Anda jual Source Code ke klien | ❌ **TIDAK BOLEH** |

- Penyedia **TIDAK BERTANGGUNG JAWAB** atas kerugian langsung, tidak langsung, insidental, khusus, atau konsekuensial yang timbul dari penggunaan atau ketidakmampuan menggunakan Source Code.

## 7. Pembatalan dan Pelanggaran

### 7.1 Pelanggaran Ketentuan

Jika Pembeli melanggar ketentuan dalam dokumen ini:

- Hak penggunaan Source Code akan **otomatis dicabut**.
- Pembeli wajib **menghapus semua salinan** Source Code.
- Penyedia berhak mengambil **tindakan hukum** yang diperlukan.

### 7.2 Tidak Ada Pengembalian Dana

- Karena Source Code adalah **bonus**, tidak ada pengembalian dana terkait Source Code.
- Kebijakan pengembalian dana hanya berlaku untuk kelas "Lolos Tech Provider" sesuai ketentuan terpisah.
